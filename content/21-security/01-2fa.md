---
title: Two-factor authentication
minutes: 6
---

Your GitHub account can push code that thousands of people run. If someone steals your password, they can put malware in your projects. **Two-factor authentication (2FA)** means a stolen password is not enough.

## Set it up

**Settings → Password and authentication → Enable two-factor authentication.** Choose one or more:

| Method | Strength | Notes |
|---|---|---|
| **Passkey** or **security key** (YubiKey, Touch ID, Windows Hello) | strongest | Cannot be phished. Recommended. |
| **Authenticator app** (Google Authenticator, Authy, 1Password) | strong | 6-digit codes that change every 30 seconds |
| **GitHub Mobile** | strong | Approve sign-ins on your phone |
| SMS | weakest | Only if nothing else works |

**Download your recovery codes** and keep them somewhere safe (a password manager, or printed). If you lose your phone without them, you can lose the account.

## Facts worth knowing

- GitHub **requires 2FA** for everyone who contributes code on github.com (rolled out from 2023).
- Organizations can **require** 2FA for all members, and remove anyone who does not have it.
- 2FA protects **sign-in**. Git pushes use tokens or SSH keys, so protect those too: short expiry, smallest scope, never shared.

```tip
Use a password manager. A unique, random password for every site plus a passkey on GitHub stops almost every account takeover.
```
