A pull request is a conversation about a change. Good ones get merged fast. This module shows you how to write them, review them and survive feedback.

## Planned lessons

- Branch, push, open a pull request
- Writing a description people want to read
- Reviewing: comments, suggestions, approvals
- Draft pull requests
- Merge, squash or rebase?
- Taking feedback without stress
