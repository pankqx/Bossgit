The final chapter. You will build **minigit**, a small Git in Node.js that writes real Git objects, and **MiniHub**, a tiny GitHub that hosts repositories, accepts pushes and merges pull requests on the server. Then you ship it the way professional teams ship software. When you finish, you understand Git from the bytes on disk up to the merge button.
