Everyone makes mistakes. Git is very good at undoing them, as long as you pick the right tool. This module gives you all of them and a map for choosing.

## Planned lessons

- git restore: throw away a change
- Unstage a file
- Fix the last commit with --amend
- git revert: undo by adding a commit
- git reset: soft, mixed and hard
- Which undo do I need?
